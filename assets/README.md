# Assets

This folder is for visual and audio assets used by the Perilous Wanderer prototype.

## Current Assets

We use free assets from Kenney (CC0 license):

- Isometric space / sci-fi sprites (for maps, locations, characters, items)
- Sci-fi sound effects
- UI elements (buttons, panels, icons)

Full packs:
- https://kenney.nl/assets/space-kit
- https://kenney.nl/assets/sci-fi-sounds
- https://kenney.nl/assets/ui-pack

## How we will use them

When we build the Pygame version, we will only include the specific sprites and sounds we actually need (not the entire packs). This keeps the repo small and clean.

For now this folder is a placeholder.
